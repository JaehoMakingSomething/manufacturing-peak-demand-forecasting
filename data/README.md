# 입력 데이터

전처리 완료 파일 `okm_전처리완료_2021.xlsx`를 이 폴더에 놓습니다. Excel 시트 이름은 `데이터`입니다. 전처리 전 원자료를 이 파일로 대체할 수 없습니다.

| 열 | 의미 |
| --- | --- |
| 날짜 | YYYYMMDD 형식 날짜 |
| 시간 | 0–23, 해당 시간 구간의 시작 |
| 15분, 30분, 45분, 60분 | 해당 시간의 15분 수요전력 측정값 |
| 최대15분 | 예측 대상, 해당 시간의 15분 최대수요전력 |
| 최대15분_래그용 | 과거 전력 피처를 계산할 때 사용하는 전처리 값 |
| 평균 | 시간 내 평균 전력, 미래 전력 변조 검사 대상 |
| 생산량 | 확정 생산계획으로 간주하는 입력값 |
| 기온, 습도, 풍속, 시간당강수량 | 기상 입력값 |
| 전기요금(계절) | 원본의 계절 구분 열 |
| 시간단위_학습사용 | 사용 가능한 시간은 1 |

후보 피처는 시간 행이 1시간 간격으로 연속이라고 가정합니다. 원본의 결측 처리·이상일 판정·래그용 값 생성까지 마친 동일 파일이 필요합니다. 이 저장소에는 원자료 전처리의 전체 과정이 포함되어 있지 않습니다.

다른 경로를 쓰려면 CLI의 `--data` 또는 환경변수 `PEAK_DATA_DIR`를 사용합니다. 데이터 파일은 Git 추적에서 제외됩니다.
