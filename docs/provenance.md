- 입력 코드: `전력피크_예측_제출용_피크고도화_조합검증.ipynb`.
- 자료에 표시된 수정일: 2026-10-03.
- 공개용 정리일: 2026-10-25.
- 대회 최종 제출본 여부와 개인별 기여도는 이 파일만으로 확인하지 못했습니다.

## 보존한 내용

전처리 함수, 후보 피처 생성 함수, 모델 학습·예측, 주 단위 평가, 지표 계산, 누수 검사, 최종 14개 피처 및 조합 비교 로직을 원본에서 가져왔습니다. 고정 모델의 종류·파라미터·표본 가중치·임계값은 변경하지 않았습니다.

## 공개를 위해 바꾼 내용

Colab의 수동 ZIP 업로드와 절대경로를 로컬 경로 및 `PEAK_DATA_DIR` 설정으로 대체했습니다. 실행 출력과 업로드 위젯을 제거했습니다. 별도 모듈과 CLI에서 같은 함수를 사용할 수 있게 구성했으며 조합 탐색은 명시적으로 실행할 때만 동작하도록 했습니다.

학습 데이터가 필요한 실행 전에 파일과 필수 열을 확인하고, 최종 평가에는 `--frozen` 플래그를 요구합니다. 이 플래그가 실제 실험 동결을 증명하지는 않습니다.

원본 설명과 실제 소스가 다른 A 학습 컷오프는 소스를 유지하고 설명을 정정했습니다. 과거 표는 별도 파일로 옮겨 현재 실행과 섞이지 않게 했습니다.

원본 데이터, 학습된 가중치, 전체 예측 CSV, 팀원 정보는 이 공개본에 포함하지 않았습니다. 새 성능이나 대회 수상 실적을 추가하지 않았습니다.
