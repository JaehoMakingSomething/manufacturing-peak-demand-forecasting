# 방법론

## 예측 시점과 타깃

타깃은 각 시간 구간의 15분 최대수요전력입니다. 시간 평균 전력이나 에너지 사용량(kWh)과 구분합니다.

A는 전날 23:00에 다음 날 24개 구간을 예측합니다. 발행 당시 아직 완료되지 않은 전날 23–24시 전력은 피처로 사용할 수 없습니다. B는 매 정각에 다음 1시간을 예측하며 완료된 직전 시간의 전력을 사용합니다.

## 시간 순서 검증

선택 구간은 2021-07-05부터 08-29까지입니다. 매주 월요일 모델을 다시 학습하고 해당 주를 예측합니다. 최종 확인 구간은 08-30부터 09-14까지이며 08-30과 09-06을 기준으로 나눕니다.

현재 소스의 학습 조건은 A에서 `ts < 주시작 - 1시간`, B에서 `ts < 주시작`입니다. 따라서 월요일 A 학습에는 직전 일요일 23시 구간이 들어가지 않습니다. 원본 마지막 설명에 적힌 “월요일 00:00 컷오프” 문구와 실제 소스가 달라 공개본에서는 실제 소스 기준으로 문서를 정정했습니다. 과거 저장 결과가 어느 코드 상태에서 생성됐는지는 다시 확인해야 합니다.

주중에는 모델을 고정하고 시점별 이용 가능한 피처로 예측합니다. “주 단위 재학습”과 “예측 발행 시각”은 서로 다른 개념입니다.

## 데이터 품질

하루 24행 × 4개의 15분 전력값이 다른 날과 완전히 같으면 복사일로 판정하고 가장 이른 날을 원본으로 둡니다. 복사일은 학습에서만 제외하며 평가 행에서는 제거하지 않습니다. 전체 기간을 이용해 복사일을 찾는 기존 방식은 유지되어, 운영 시점까지의 정보만 사용하는 중복 탐지와 비교가 필요합니다.

`시간단위_학습사용 == 1`인 행만 평가에 사용합니다. 기존 저장 결과는 최종 16일의 384개 시간 중 383개를 평가했습니다.

## 피처와 모델

기준 A 피처는 달력, 생산계획, 기상, 같은 계획가동상태의 과거 전력입니다. 기준 B는 직전 1·2시간 전력을 추가합니다. 고정 최종 세트는 A와 B 각각 14개이며 상세 목록은 소스의 `FINAL_A`, `FINAL_B`에서 확인합니다.

기준 모델은 LightGBM과 Random Forest입니다. 고도화 후보는 0.60/0.65 분위수 회귀와 피크 가중치의 조합입니다. 가중치는 실제 180kW 이상 표본에 2, 185kW 이상 표본에 3을 적용합니다. 0.65 분위수 예측을 65%의 피크 검출 확률이나 검증된 신뢰 상한으로 해석하지 않습니다.

선택 구간의 조합 비교는 같은 고도화 모델의 기준 피처 대비 전체 MAE 증가를 1kW 이내로 제한하고, 피크 MAE, 과소예측 P95, Peak Recall 순으로 정렬합니다. 조합 코드는 권장 후보를 출력하며 고정 최종 피처를 자동 변경하지 않습니다.

## 피크 지표

실제 180kW 이상인 행을 피크, 185kW 이상을 극단 피크로 정의합니다.

- MAE: 모든 평가 시간의 평균 절대오차.
- 피크 MAE: 실제 피크 행의 평균 절대오차.
- 피크 과소예측 평균: 실제 피크 행 전체에서 `max(실제-예측, 0)`의 평균.
- 과소예측 P95: 위 과소예측값의 95백분위수. 과대예측한 피크 행은 0으로 포함.
- Peak Recall / Precision: 실제값·예측값 각각에 180kW 기준을 적용한 검출 지표.

선택 구간에서는 시드 42, 7, 2024별 지표를 평균합니다. 최종 평가는 시드 42를 사용합니다.

## 현장 적용에 필요한 추가 검증

생산량의 계획·실적 구분과 계획 확정 시각, 실제 기상예보의 발행 버전, 계측 완료·전송 지연은 이 코드로 증명되지 않습니다. 현재 실험은 생산계획과 미래 기상을 사용할 수 있다고 가정합니다.

미래 전력 변조 검사는 전력 피처의 시점 의존성을 확인하며 생산계획과 기상의 입수 가능성까지 확인하지 않습니다. 전체 기간의 복사일 탐지, 평가에 남은 복사일, 피크 기준의 민감도, 다른 계절·기간에서의 일반화도 추가 검증 대상입니다.

시간별 최대값의 예측만으로 작업 이동의 효과를 추정할 수 없습니다. 작업별 전력, 설비·인력·선행공정·납기 제약 없이 절감액이나 실행 가능한 최적 스케줄을 주장하지 않습니다.
