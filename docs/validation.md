# 공개본 검증 기록

검증일: 2026-10-25

- 합성 데이터 기반 회귀 검사 8개 통과.
- A: 전날 23시 미완료 전력 구간을 월요일 학습에서 제외.
- B: 완료된 직전 전력 구간을 월요일 학습에 사용.
- 복사일 학습 제외, A의 B 전용 피처 사용 차단 확인.
- 최종 A/B 피처가 발행 이후 전력 변조에 영향을 받지 않는 합성 사례 확인.
- 피크 지표의 임계값, 분모, 피크 과소예측에 포함하는 0값 확인.
- 추출한 핵심 함수 22개의 Python AST가 원본과 동일함을 확인.
- Python 및 노트북 코드 셀의 구문, 문서 내부 링크 확인.
- 과거 성능표 CLI 출력 확인. --frozen 없는 최종 평가 차단 확인.

이 검사는 특정 합성 사례 및 코드 구조를 검증합니다. 실제 데이터에서의 전면 누수 부재, 생산계획·기상 입수 가능성, 새로운 예측 성능을 증명하지 않습니다. 전처리 Excel과 전체 예측 CSV가 없어 실제 재학습과 성능 재계산은 수행하지 않았습니다.
